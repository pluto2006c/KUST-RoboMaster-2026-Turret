# 虚拟遥控器系统调研报告

## 系统架构概述

本项目实现了一套**多源遥控器数据融合系统**。多个物理输入设备（DJI DBUS 遥控器、DJI VT03 虚拟发射器、PC 串口）各自写入 `user_device_remote[]` 数组的不同槽位，`data_fusion()` 函数将所有输入求和/限幅后输出到统一的 `virtual_user_remote` 结构体，供控制逻辑读取。

**不存在**图形界面虚拟摇杆 —— "虚拟"遥控器是多物理输入源的软件融合抽象。

---

## 核心数据结构

### `USER_REMOTE`（`User_Drives/User_remote/user_remote.h:19-31`）
融合后的虚拟遥控器数据结构：

| 字段 | 类型 | 说明 |
|------|------|------|
| `chassis_x`, `chassis_y` | int16_t | 底盘平移轴，范围 -660..660 |
| `yaw`, `pitch` | int16_t | 云台瞄准轴，范围 -660..660 |
| `wheel` | int16_t | 滚轮/辅助轴 |
| `shoot_by_user` | int16_t | 手动开火命令 (0/1) |
| `shoot_by_ai` | int16_t | AI/自动开火命令 (0/1/2) |
| `control_mode` | uint8_t | 0=手动射击, 1=保险关闭, 2=自动模式 |
| `key_middle` | uint8_t | 鼠标中键/暂停（摩擦轮启停） |
| `custom_key[14]` | uint8_t[] | 自定义按键（各外设不同） |
| `remote_config` | 函数指针 | 控制回调（如 `ZhouZishun_Config`） |

## 输入源驱动

### 1. DJI DBUS 物理遥控器
- **文件**: `User_Drives/User_remote/user_dji_bus.h`, `Src/user_dji_bus.c`
- **通信**: USART1, 100000 baud, 8E1（DJI SBUS 协议）
- **数据**: 4 通道 (ch0-ch3) + 滚轮 + 2 个三档开关 (sw1/sw2)
- **映射**: `DJI_Bus_Process()` → `chassis=ch3/ch2`, `yaw=ch0`, `pitch=ch1`, `wheel=roll`, `control_mode` 由 sw1 决定
- **写入槽位**: `user_device_remote[0]`

### 2. DJI VT03 虚拟发射器（键鼠+摇杆）
- **文件**: `User_Drives/User_remote/user_dji_vt03.h`, `Src/user_dji_vt03.c`
- **通信**: USART3, 921600 baud
- **协议**: 21 字节帧，头 `0xA9 0x53`，CRC16 校验
- **数据**: 4 摇杆通道 + 模式开关 + 暂停 + 功能键 + 滚轮 + 扳机 + 鼠标(xyz+3键) + 键盘(16键位)
- **映射** (`DJI_VTO3_Process()`, line 125-140):
  - `chassis_x = ch0 + W*660 - S*660`
  - `chassis_y = ch1 + D*660 - A*660`
  - `yaw = ch2 + mouse_x`
  - `pitch = ch3 + mouse_y`
  - `wheel = wheel + mouse_z`
  - `shoot_by_user = trigger + mouse_left`
  - 自动开火: control_mode==2 且手动开火, 或 mouse_right==1
- **写入槽位**: `user_device_remote[1]`（自动分配）

### 3. PC 串口（AI 视觉链路）
- **文件**: `User_Drives/User_remote/PC_communication.h`, `Src/PC_communication.c`
- **通信**: USART6, 921600 baud
- **协议**: 头 `0xEB 0x90`，尾 `0x90 0xEB`，14 字节
- **数据**: `holder_pitch` (float), `holder_yaw` (float), `shoot_delay` (uint16)
- **注意**: PC 数据**不写入** `user_device_remote[]`，而是通过 `user_PC` 全局变量单独使用，在 `ZhouZishun_Config()` 中直接读取

## 数据融合与分发

### 融合函数 `data_fusion()`（`User_Drives/User_remote/Src/user_remote.c:24-66`）
- 清零 `virtual_user_remote` 所有字段
- 遍历所有已注册的 `user_device_remote[0..N]`，逐字段求和
- 每步限幅：轴类 ±660，布尔类 ±1
- 特殊处理：`control_mode` 直接覆盖（取最后一个注册源的值）

### 定时调度 `Mech_Operating_Config()`（`user_remote.c:77-88`）
- 必须放在 SysTick 中断中
- 每次调用：递增软件计时器 → 调用 `data_fusion()` → 执行 `remote_config()` 回调

### 初始化流程（`main.c:151-161`）
```
DJI_VT03_Init()    → 注册 VT03 UART 回调，分配槽位号
DBUS_Init()         → 配置 UART1 DMA
PC_Init()           → 注册 PC UART 回调
user_remote_init()  → 设置融合输出指针 + 注册 ZhouZishun_Config 回调
```

## 消费端：`ZhouZishun_Config()`（`Controller_config/Src/ZhouZishun.c`）

读取 `virtual_user_remote` 控制以下电机：
- **Pitch 轴**: `PICH_GM6020` ← `virtual_user_remote.pitch`
- **拨弹**: `TP_M2006` ← 状态机控制，受 `shoot_mode` 约束
- **摩擦轮**: `RW_M3508` / `LW_M3508` ← 根据 `control_mode` 启停
- **AI 自动射击**: 读取 `user_PC.shoot_delay` + `shoot_by_ai`，通过 UART 发送回 PC 角度数据
