# 删除不用的 MiMoCode 模型

## 当前状态

你的 MiMoCode 配置中有以下模型：

### 配置文件位置
- **主配置**: `E:\mimocode\config\mimocode.jsonc` — 当前只配了一个模型
- **全局配置**: `C:\Users\Pluto\.config\mimocode\mimocode.jsonc` — 几乎为空

### 当前配置的模型
`E:\mimocode\config\mimocode.jsonc` 中只有：
```jsonc
{
  "provider": {
    "xiaomi": {
      "models": {
        "DeepSeek": {
          "name": "DeepSeek v4"
        }
      }
    }
  }
}
```

### 可用模型缓存
`E:\mimocode\cache\models.json` 是 MiMoCode 从各 provider 拉取的模型目录（StepFun、小米等），这个是**缓存文件**，不是你手动配置的。

## 如何删除不用的模型

### 方法 1：删除配置中的模型
编辑 `E:\mimocode\config\mimocode.jsonc`，把不需要的模型条目删掉。比如你要删掉 DeepSeek v4，把整个 `provider` 块清空：

```jsonc
{
  "$schema": "https://mimo.xiaomi.com/mimocode/config.json"
}
```

### 方法 2：用 `disabled_providers` 禁用整个 provider
如果你不想用某个 provider 下的所有模型：

```jsonc
{
  "$schema": "https://mimo.xiaomi.com/mimocode/config.json",
  "disabled_providers": ["stepfun-step-plan"]
}
```

### 方法 3：删除模型缓存
`E:\mimocode\cache\models.json` 是自动拉取的缓存，删掉后 MiMoCode 会在下次启动时重新拉取。如果你只是想清理缓存：

```bash
del "E:\mimocode\cache\models.json"
```

## 注意事项
- `models.json` 缓存是 MiMoCode 自动管理的，不需要手动维护
- 你只需要关注 `mimocode.jsonc` 配置文件中的 `provider` 和 `model` 相关字段
- 参考文档：`E:\mimocode\data\builtin_skills\0.1.6\skills\mimocode\reference\config.md`

## 验证
修改配置后重启 MiMoCode 即可生效。
